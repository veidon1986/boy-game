# Инструкции для агента — BoyGame

## 🚫 Деплой только по команде

- **Никогда не выполняй `git push` и не публикуй сайт без явной команды пользователя.**
  Ветка `main` подключена к GitHub Pages: любой пуш автоматически деплоит
  https://veidon1986.github.io/boy-game/
- После готовности изменений: проверь их, покажи результат и **спроси разрешение**.
  Пуш выполняй только после явного «пушь / деплой / публикуй».
- Разрешено без подтверждения: правки файлов, запуск локального сервера, проверка
  в браузере, `git add`, `git commit`.
- Запрещено без явного запроса: `git push`, `git push --force`, теги релизов,
  изменение настроек GitHub Pages.

## Порядок публикации (когда разрешено)

1. Поднять версию кэша в `sw.js`: `boygame-vNN` → `boygame-vNN+1`.
2. Обновить `ASSETS` в `sw.js`, если добавлены/удалены файлы.
3. `git add -A && git commit -m "..."` затем `git push origin main`.
4. Подождать 1–2 минуты (сборка Pages) и проверить живые URL.

## Проект

- Чистый HTML/CSS/JS без сборки; PWA с service worker (`sw.js`).
- Проверка: `python3 -m http.server 8765`, затем браузер. При правках фронтенда
  сбрасывать service worker и кэш (или поднимать версию в `sw.js`).
- Данные детей хранятся только локально (localStorage), их нельзя терять.

## Безопасность данных

- Профили: `boygame.profiles`; данные ребёнка `boygame.d.<id>.*`.
- Не удалять и не перезаписывать эти ключи при тестах в «живом» браузере.
