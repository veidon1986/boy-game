## Обновление старой версии

Стенд `tools/release-check-server.py` запускает старый и текущий код на одном
изолированном origin. До первого скрипта приложения подставляется хранилище
в памяти родительской страницы; IndexedDB получает уникальное имя
`boygame-test-upgrade-*`. Настоящее localStorage приложению недоступно.

Проверены:

- создание двух вымышленных профилей через API старого Store;
- сохранение результатов, звёзд, наград, личных рекордов, рейтинга шахмат,
  уровня загадок, возраста, активного профиля, дневного лимита и использования;
- обнаружение нового Service Worker, показ предложения обновиться и принятие
  через реальную кнопку приложения;
- побайтовое сохранение всех прежних значений в хранилище;
- импорт старой истории, запись новой задачи, разделение истории между детьми;
- перезагрузка без сети и загрузка шахмат вместе с движком из нового кэша.

Вместо изменения настроек сети сервер прекращает отвечать только на запросы
тестовой копии `/app/`. Пользовательские вкладки не участвуют в проверке.

## Прохождение игр

`tests/playthrough.test.cjs` использует настоящие обработчики нажатий и переходов,
хранилище Map, виртуальные часы и упрощённые DOM/canvas.

- Для 14 игр с сессиями: полное завершение, запись трёх звёзд за правильные ответы,
  повторный запуск с новыми заданиями и выход. Доступные через выбор сложности
  возрастные варианты проверяются на русском и английском. В «Найди такого же»
  проверяются начальные уровни соответствующих возрастов.
- Отдельно проверены ошибки в математике, последовательностях, поиске лишнего,
  сопоставлении картинок, чтении и симметрии: награда уменьшается.
- «Умные загадки»: все 30 уровней и сохранение прогресса.
- «Дракончик»: выполнение кадров отрисовки, прыжок, возвращение на землю,
  столкновение, рекорд, повторный запуск и очистка обработчиков.
- «Падающие фигуры»: пауза, возобновление, защита от двойного события
  pointerdown/click, завершение, рекорд и повторный запуск.
- Шахматы: 9 уроков ходов, 5 уроков взятий, исчерпание заданий, продолжение
  обучения с сохранённой историей, мат в партии вдвоём, журнал, координаты,
  ответ компьютера, завершение по времени и однократное изменение рейтинга.
- Шашки: 3 урока ходов, 4 урока взятий, исчерпание заданий и полная партия
  с допустимыми ходами до результата и повторного старта.

Ответы в этих сценариях берутся из данных генераторов. Проверяется обработка
ответов и жизненный цикл, а не педагогическая корректность каждого задания.
Это не ручное прохождение всех игр и не проверка отображения на телефоне.

## Исправленные ошибки

1. **Найди пару:** финальный таймер не сохранялся для отмены. При быстром выходе
   он мог завершить уже новую сессию той же игры. Теперь отменяется при выходе.
2. **Шашки:** меню оставалось над начавшейся партией и сдвигало доску вниз.
   Теперь экран очищается перед созданием партии.
3. **Симметрия:** ошибки не влияли на число правильных ответов с первой попытки.
   Теперь оценка учитывает ошибки каждого раунда; старые результаты не меняются.
4. **Урок рокировки:** перемещение ладьи зависело от номера урока в списке.
   После продолжения курса список сокращался, и ладья оставалась на месте.
   Теперь действие определяется свойством самого урока.
5. **Подбор разных типов заданий:** математика, последовательности и поиск
   лишнего записывали в историю также промежуточные варианты, которые не были
   показаны. При ограниченном наборе это могло преждевременно прервать сессию.
   Предпочтительный тип теперь выбирается до записи; сохраняется только выданное
   задание. Проверка добавлена при подготовке публикации.

## Производительность

Два прогона по 9 парных запусков на локальном компьютере, без HTTP-кэша,
без установки Service Worker, профиль только в памяти (`?test=1`). Порядок старой
и новой версии чередуется. Запуск игры измеряется до ближайшего кадра.

| Показатель | Старый релиз, медиана | Новый релиз, медиана |
| --- | ---: | ---: |
| Меню, первый прогон | 69,5 мс | 47,7 мс |
| Меню, второй прогон | 82,9 мс | 70,7 мс |
| Первый запуск «Найди пару», первый прогон | 8,8 мс | 15,5 мс |
| Первый запуск «Найди пару», второй прогон | 4,7 мс | 10,7 мс |
| Повторный запуск, первый прогон | 15,1 мс | 14,9 мс |
| Повторный запуск, второй прогон | 15,3 мс | 15,2 мс |
| JavaScript меню, размер без сжатия | 377 384 байта | 212 839 байт |
| Запросы JavaScript в меню | 30 | 26 |
| Игровые модули, выполняемые в меню | 19 | 0 |

Объём JavaScript для меню уменьшился на 43,6%. Первый запуск игры добавляет
загрузку её модуля. Миллисекунды чувствительны к нагрузке и ожиданию кадра;
по этим данным нельзя обещать такой же процент ускорения на телефоне или в сети.
Миграция IndexedDB и установка PWA не входят в этот замер.

## Мобильная компоновка

В браузере на размерах 390×844, 360×640 и 844×390 поле и управление
«Падающих фигур» укладываются в экран. Горизонтального переполнения документа
на 390×844 не обнаружено. На 390×844 доска шашек после исправления полностью
видна, меню партии отсутствует.

Это изменение viewport в настольном браузере. Физические iPhone/Safari и
Android/Chrome не проверялись. Осталось проверить касания и удержание, поворот,
переход в фон и возврат, звук и анимации, обновление установленной PWA на устройствах.

## Воспроизведение

```bash
node tools/sync-assets.cjs --check
node --test tests/*.test.cjs
python3 tools/release-check-server.py --baseline 35e1181 --port 8787
```

На **свободном, ранее не использованном тестовом порту** откройте
`http://127.0.0.1:8787/fixture/` для обновления, либо `/performance/` для замеров.
Для повторного сценария обновления перезапустите сервер на другом свободном порту:
это исключит влияние установленного тестового Service Worker.
Для 5 проверок IndexedDB откройте `tests/browser-storage.html` с обычного
локального сервера. Они используют только уникальные временные тестовые базы.

Вспомогательные страницы не входят в офлайн-манифест приложения.
