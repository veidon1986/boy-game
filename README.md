# 🎲 Игры для детей (PWA)

Развивающее приложение для детей **2–8 лет**. У каждого ребёнка в профиле указан
**возраст**, и приложение показывает игры, подходящие именно ему. Работает офлайн,
устанавливается на телефон или планшет как обычное приложение. Интерфейс на
**русском и английском**.

## Возрастные группы

| Возраст | Эмодзи | Игры |
|---------|--------|------|
| 2–3 года | 🧸 | 👀 Найди такого же, 🧩 Собери картинку |
| 4–5 лет | 🎨 | 🧠 Найди пару, 🔢 Что дальше?, 🧩 Разложи по группам, 🔍 Что лишнее?, ➕ Счёт и примеры, 👀 Найди такого же, 🧩 Собери картинку, 🌘 Найди тень, 📖 Что сначала?, 🧠 Умные загадки |
| 5–6 лет | 🎒 | 🧠 Найди пару, 🔢 Что дальше?, 🧩 Разложи по группам, 🔍 Что лишнее?, ➕ Счёт и примеры, 🧩 Собери картинку, 🧠 Умные загадки, 🧭 Дорога домой, 🪞 Симметрия, 🐉 Дракончик (открывается позже), 🧱 Падающие фигуры (Мастер), 🔴 Шашки вдвоём (Гений) |
| 7–8 лет | 📚 | 🧠 Найди пару, 🔢 Что дальше?, 🧩 Разложи по группам, 🔍 Что лишнее?, ➕ Счёт и примеры, 🧠 Умные загадки, 🧭 Дорога домой, 🪞 Симметрия, 🤖 Программируем робота, 🔠 Слова из букв, 🔤 Найди слово, 🐉 Дракончик, 🧱 Падающие фигуры (Мастер), 🔴 Шашки вдвоём (Гений) |

Возраст задаётся при создании профиля и меняется в любой момент в профиле ребёнка.
Набор игр, число наград и максимум звёзд пересчитываются под выбранный возраст.

| 🌘 **Найди тень** | Сопоставление формы предмета с силуэтом | 4–5 |
| 📖 **Что сначала?** | Понимание порядка событий и бытовых последовательностей | 4–5 |

| 🔠 **Слова из букв** | Чтение и составление слов из букв | 7–8 |

| 🧱 **Падающие фигуры** | Пространственное мышление и планирование | 5–8, открывается на ранге «Мастер» |
| 🔴 **Шашки вдвоём** | Планирование, правила и игра по очереди | 5–8, открывается на ранге «Гений» |

В играх-заданиях доступны уровни сложности (Легко / Средне / Сложно) с учётом
возраста, звёздочки за результат и сохранение прогресса на устройстве.
**«Умные загадки»** — отдельная последовательность из 30 уровней.
**«Дракончик»** — это аркада-бонус: без уровней и звёзд, только личный рекорд
(он показан на его карточке), и открывается на статусе **«Умник»**.
«Падающие фигуры» — спокойная игра с блоками без звёзд и кубков. «Шашки вдвоём»
позволяют сыграть локальную партию на одном устройстве; игра также не выдаёт
звёзды и кубки.

## Как запустить

Приложению нужен локальный веб-сервер (это требование PWA и service worker).

```bash
cd BoyGame
python3 -m http.server 8123
```

Затем откройте в браузере: **http://localhost:8123**

## Как открыть на телефоне (в той же Wi-Fi сети)

1. Узнайте IP компьютера: `ipconfig getifaddr en0` (macOS).
2. Запустите сервер как выше (можно с `--bind 0.0.0.0`).
3. На телефоне откройте `http://<IP-компьютера>:8123`.

## Как установить как приложение

- **Android / Chrome**: меню браузера → «Добавить на главный экран».
- **iPhone / Safari**: кнопка «Поделиться» → «На экран “Домой”».

После установки приложение открывается без адресной строки и работает без интернета.

## Как добавить свою игру

Создайте файл `js/games/my.js` и подключите его в `index.html` после `js/app.js`.

```js
(function (global) {
  'use strict';
  var el = UI.el;

  function start(root, App) {
    // root — контейнер экрана, можно добавлять свои элементы через el(...)
    root.appendChild(el('p', { class: 'game-hint' }, 'Моя игра'));

    var btn = el('button', { class: 'btn primary', onclick: function () {
      // когда игра закончена — показать звёзды (1..3)
      App.finishGame('my', 3, function () { /* снова */ });
    } }, 'Готово!');
    root.appendChild(btn);

    // верните функцию очистки (снять таймеры), если нужно
    return function () {};
  }

  App.register({
    id: 'my',
    ages: ['preschool', 'junior', 'school'], // для кого игра: toddler / preschool / junior / school
    emoji: '🎈',
    titleKey: 'game.my',       // добавьте пару строк в js/i18n.js
    descKey: 'game.my.desc',
    start: start
  });
})(window);
```

Затем добавьте тексты в `js/i18n.js` (ключи `game.my` и `game.my.desc`) и не
забудьте указать новый файл в списке `ASSETS` внутри `sw.js`, чтобы он кэшировался.
Поле `ages` определяет, при каком возрасте ребёнка показывать игру; если его
не указать, игра считается доступной для всех возрастов.

## Полезные детали

- **Сброс прогресса**: откройте консоль браузера и выполните `Store.reset()`, затем перезагрузите страницу.
- **Звук** включается/выключается кнопкой 🔊 в шапке.
- **Язык** переключается кнопкой RU/EN в шапке.
- Прогресс хранится только на устройстве и никуда не отправляется.

## Адаптивная сложность и разнообразие

- **Без повторов**: внутри одной сессии задания не повторяются (по ключу
  содержимого), а в «Найди пару» и «Разложи по группам» новое поле всегда
  отличается от предыдущего.
- **Адаптивная сложность**: 3 задания подряд без ошибок — уровень повышается;
  2 ошибки — понижается. Появляется подсказка «Сложнее/Проще».
- В играх с одним полем (память, сортировка) уровень меняется между полями:
  после результата показывается «Следующий уровень: …», и кнопка «Ещё раз»
  запускает уже новую сложность.
- Уровень всегда можно задать вручную кнопками Легко / Средне / Сложно.

## Профиль, награды и статусы

- **Первый запуск** спрашивает имя, **возраст** и предлагает выбрать аватарку
  (16 смайликов). Профиль меняется по нажатию на карточку профиля на главном
  экране; там же виден возраст ребёнка.
- **Значки наград видны прямо в профиле** на главном экране: открытые — яркие
  в золотой рамке, ещё не полученные — приглушённые. Нажатие на значочки
  открывает полный список наград.
- **Кубки** выдаются за завершение каждой игры на каждом доступном возрасту
  уровне сложности: 🥉 бронзовый за лёгкий, 🥈 серебряный за средний,
  🥇 золотой за сложный. Для возрастов 2–3 доступны только бронзовые кубки,
  для 4–5 — бронзовые и серебряные, для 5–8 — все три вида. Кубок не зависит
  от количества звёзд за раунд.
- ⭐ **Звёзды прохождения** по-прежнему оценивают каждый отдельный раунд: за него
  можно получить до трёх звёзд. Эти звёзды не заменяют кубок за сложность.
- Дополнительные награды:
  - 🌟 накопленные звёзды (пороги считаются от максимума звёзд возраста);
  - 🏅 пройдены все игры.
Примеры с текущим набором игр:

  | Возраст | Всего наград | Максимум звёзд |
  |---------|--------|---------------|
  | 2–3 | 6 | 6 |
  | 4–5 | 24 | 30 |
  | 5–6 | 31 | 27 |
  | 7–8 | 37 | 33 |
  При новой награде показывается праздничное окно, а на главной кнопка
  «🏆 Награды» открывает список всех наград (открытые и закрытые).
- **Статус (ранг)** растёт по числу открытых наград:
  🌱 Новичок → 🧭 Исследователь → 🧠 Умник → 🎓 Мастер → 👑 Гений.
- Статистика ведётся отдельно по каждой игре и каждому уровню сложности,
  поэтому «3★ на среднем» не потеряется при переходе на сложный.

## 👨‍👩‍👧‍👦 Несколько детей на одном устройстве

- **У каждого ребёнка свой профиль** (имя, возраст + аватарка). Прогресс, звёзды, награды,
  рекорд «Дракончика» и дневной лимит хранятся **отдельно для каждого**.
- Кнопка **«👥 Дети»** на карточке профиля открывает переключатель: видно, кто
  сейчас играет, сколько у каждого наград и звёзд.
- **Первый профиль** создаётся при первом запуске свободно (решает сам ребёнок).
  **Добавление следующего ребёнка (➕) и удаление профиля (🗑)** защищены примером
  на умножение — как и родительские настройки, чтобы дети не добавляли и не
  удаляли профили сами. Удаление дополнительно просит подтверждение.
- Всё хранится только на этом устройстве; между устройствами данные **не
  синхронизируются**. Старый одиночный профиль автоматически переносится в новый
  формат при первом запуске.

## 🐉 Игра «Дракончик»

- Бесконечный раннер в стиле офлайн-динозаврика Chrome: тап по экрану (или
  Пробел) — прыжок, скорость постепенно растёт.
- **Открывается на статусе «Умник»** (8 наград). До этого карточка показана с
  замком 🔒 и подсказкой, сколько наград ещё нужно.
- **Без звёзд и наград** — только личный рекорд (у каждого ребёнка свой).
  Поэтому бонусные игры не увеличивают максимум звёзд и не добавляют кубки.

## 🧠 Игра «Умные загадки»

- 30 уровней: первые шесть — короткий разогрев, затем идут загадки-ловушки.
- Ответ выбирается из четырёх вариантов. За прохождение начисляются звёзды,
  а открытый уровень сохраняется отдельно в профиле ребёнка.
- Доступна детям 4–8 лет.

## Новые игры

- **Собери картинку**: уложи части в нужные места. Для малышей — две крупные
  части; сложность можно увеличить до четырёх.
- **Найди тень**: выбери силуэт, который соответствует предмету.
- **Что сначала?**: нажимай картинки в хронологическом порядке.
- **Дорога домой**: веди героя по соседним клеткам лабиринта.
- **Симметрия**: выбери цвет, который зеркально продолжает узор.
- **Программируем робота**: составь последовательность команд и запусти её.
- **Слова из букв**: собери слово по картинке; набор слов меняется вместе с языком.

## ⏳ Лимит времени (для родителей)

- **Дневной лимит активной игры.** Считается только время, проведённое внутри
  игры (меню, окна и главный экран — не в счёт). Сброс автоматически в полночь.
- На главной показывается чип **«⏳ Осталось»**. Во время игры за **5 минут** и за
  **1 минуту** до конца появляется предупреждение. Когда время вышло — текущую
  игру дают доиграть, а новые запускаются только завтра: показывается экран
  «🌙 На сегодня хватит!».
- Кнопка **«🔒 Для родителей»** внизу главного экрана. Вход защищён простым
  примером на умножение (чтобы ребёнок не снял лимит сам). Если детей несколько,
  внутри сначала выбирается ребёнок, а затем задаётся лимит именно для него:
  10 / 15 / 20 / 30 / 45 / 60 минут или **«Без лимита»**, а также
  **«Сбросить сегодня»**. По умолчанию — **20 минут в день у каждого ребёнка**.
